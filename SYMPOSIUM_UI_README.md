# MMPPE Symposium UI Build — November 18, 2026

Start with `START_MMPPE.bat`. The local service normally runs on port 8100.

- Moderator: http://127.0.0.1:8100/showcase
- Observer: http://127.0.0.1:8100/observer
- Participants: http://127.0.0.1:8100/p1, /p2, /p3

**Live demo sequence:** Open Moderator, select Social Influence and Judgment, load, open P01/P02/P03 in separate tabs, open Observer, start, advance through phases, submit responses from participant tabs, show observer events, export session ZIP.

This is a software-only demo. Participant inputs are entered in browser windows for presentation purposes. No EEG/ECG/EMG/GSR/eye tracking/audio/video streams are acquired.

This build does not change the ARL laboratory controller. Keep your original installation and do not replace it.
