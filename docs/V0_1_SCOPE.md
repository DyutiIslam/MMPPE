# MMPPE V0.1 scope

V0.1 is an architectural bootstrap, not a feature-complete experiment runner.

## Established now
- clean package boundary
- generic experiment schema/registry
- N=1 and N>5-capable participant identifiers
- device/vendor-neutral LSL discovery
- neutral MMPPE marker stream
- ARL isolated as a future experiment module

## Next: V0.2
Implement the generic experiment runtime/phase engine and standardized event records while preserving this interface boundary.
