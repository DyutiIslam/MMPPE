How MMPPE works

1. Define the study

What happens, how many participants take part, and what data should be collected.

2. Prepare the session

Confirm participants and match available data sources to the study requirements.

3. Run together

MMPPE executes the protocol while keeping experimental events and data sources on one timeline.

4. Organize the data

Responses, events, stream metadata, and later recordings are associated with the same session.

Device independence: the study asks for a modality such as EEG or motion—not a manufacturer. At session setup, a compatible LSL data stream is assigned to that requirement.
